Что можно проверить

Переключите разделы: обзор отражает содержимое репозитория и не подменяет запущенный интерфейс GLPI.

Один compose project

Явные сети, healthcheck, restart policy, зависимости запуска и лимиты ресурсов.

Короткие команды

make up, make health, make logs и make down.

Готовый dashboard

Доступность, задержка HTTP, MariaDB, CPU, память и файловые системы.

Четыре источника метрик

Blackbox, mysqld exporter, cAdvisor и node exporter.

Цельный бэкап

SQL dump и GLPI-файлы получают SHA-256 и manifest в каталоге с UTC-временем.

Защищённый restore

Проверка checksum и точное подтверждение целевой базы до замены данных.

Статические проверки

ShellCheck, yamllint, JSON, Compose, Nginx и promtool.

Smoke test

Pull request и ручной запуск поднимают полный стек и выполняют health check.
