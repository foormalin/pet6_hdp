# Заканчивается место на диске

## Симптом

Grafana показывает высокий процент файловой системы, база пишет `No space left on device` или контейнеры не стартуют.

## Проверка

```bash
df -h
docker system df
du -sh backups/* 2>/dev/null | sort -h
```

## Действия

1. Сначала создайте и вынесите проверенный бэкап, если свободного места достаточно.
2. Удалите только заведомо ненужные локальные бэкапы после подтверждения внешней копии.
3. Очистите неиспользуемые Docker build cache и images точечными командами после проверки списка.
4. Увеличьте диск, если рост связан с бизнес-данными.
5. Не удаляйте named volumes `db_data` и `glpi_data`.

## Подтверждение

```bash
df -h
docker system df
make health
```

Проверьте, что свободное место выше рабочего порога и продолжает стабильно меняться.
